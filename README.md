# VoicePad — локальный голосовой блокнот (Android / любой браузер)

Диктуете — Whisper набирает текст. **Полностью локально, на устройстве, без серверов и Termux.**
Языки: русский, украинский, английский (кнопки RU / UA / EN).

Приложение — PWA: открывается по ссылке, устанавливается на главный экран.
Распознавание речи выполняет модель **Whisper (ONNX, 4-бит)** прямо в браузере
через [ transformers.js ](https://github.com/huggingface/transformers.js) —
на GPU (WebGPU) или на процессоре (WASM) для старых устройств.

## Установка (5 минут, без программирования)

### 1. Залить на GitHub

1. Создайте репозиторий, например `voicepad`.
2. Загрузите в него **все файлы проекта** (index.html, app.js, whisper-worker.js, style.css, sw.js, manifest.json, папку icons).
3. В репозитории: **Settings → Pages → Source: `main` / `(root)` → Save**.
4. Через минуту приложение доступно по адресу:
   `https://ВАШ-ЛОГИН.github.io/voicepad/`

### 2. Установить на телефон

1. Откройте ссылку в **Brave** (или Chrome).
2. Разрешите доступ к микрофону.
3. Меню браузера (три точки) → **«Добавить на главный экран»**.
4. Запускайте с рабочего стола — открывается как обычное приложение.

**Первый запуск** требует интернет: скачается модель (small ~130 МБ по умолчанию; large ~500 МБ; base ~80 МБ; tiny ~40 МБ).
Показывается прогресс-бар. Дальше — **полный офлайн**, модель кэшируется браузером.

## Функции

- Диктовка кнопкой **«Диктовать»** или клавишей **F2** (Esc — стоп); текст появляется по мере речи
- Переключение языка RU / UA / EN — в том числе посреди диктовки
- Набор с клавиатуры, редактирование, автосохранение
- Заметки: поиск, сортировка (по дате, по названию)
- Экспорт заметки или всех заметок в `.txt`
- Выбор модели: **base** (точнее, по умолчанию) / **tiny** (быстрее, для слабых телефонов)
- Тёмная тема, горячие клавиши, работа без интернета

## Как это работает

- Браузер пишет звук с микрофона, нарезает на 4-секундные чанки и передаёт их в Web Worker.
- В воркере модель Whisper (ONNX, квантование q4) распознаёт чанк — на GPU через WebGPU,
  если его нет (старый телефон) — автоматически переключается на WASM с маленькой моделью tiny.
- Распознанный текст дописывается в заметку через пробел.
- Заметки хранятся локально в браузере (localStorage). Ничего никуда не отправляется.

## Требования

- Современный браузер на Chromium (Brave, Chrome) или Safari 17+.
- WebGPU (быстрый режим): Android — Chrome/Brave 121+, желательно свежие версии.
- Без WebGPU приложение всё равно работает, но в медленном WASM-режиме с моделью tiny.
