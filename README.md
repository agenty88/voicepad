# VoicePad — локальный голосовой блокнот (Android + Brave)

Диктуете — Whisper на телефоне набирает текст. Полностью офлайн.
Языки: русский, украинский, английский (переключение кнопками RU / UA / EN).

Приложение — это PWA (открывается по ссылке, устанавливается на главный экран),
распознавание речи выполняет **whisper.cpp** с моделью `base`, запущенный
локально в **Termux** на этом же телефоне.

---

## Часть 1. Залить приложение на GitHub

1. Создайте репозиторий на GitHub, например `voicepad`.
2. Загрузите в него всё содержимое этой папки (кроме `termux/` — он нужен только для телефона, но вреда от него нет).
3. В репозитории: **Settings → Pages → Source: `main` / `(root)` → Save**.
4. Через минуту приложение будет доступно по адресу:
   `https://ВАШ-ЛОГИН.github.io/voicepad/`

## Часть 2. Установить Whisper на телефон

1. Установите **Termux** только с F-Droid или GitHub (версия из Play Market устарела): https://f-droid.org/en/packages/com.termux/
2. Скопируйте на телефон папку `termux/` (или создайте файлы вручную) и выполните:

```sh
cd ~/termux
bash install.sh
```

Скрипт поставит компилятор, соберёт whisper.cpp и скачает модель base (~150 МБ). Займёт 10–20 минут.

3. Запустите сервер:

```sh
bash ~/start-whisper.sh
```

Оставьте эту сессию Termux открытой (сворачивать можно). Чтобы сервер стартовал сам при включении телефона — поставьте дополнение **Termux:Boot** и положите `start-whisper.sh` в `~/.termux/boot/`.

4. В настройках Android: **Приложения → Termux → Батарея → «Без ограничений»** — иначе система может убить сервер в фоне.

## Часть 3. Установить приложение в Brave

1. Откройте в Brave ссылку `https://ВАШ-ЛОГИН.github.io/voicepad/`
2. Разрешите доступ к микрофону.
3. Меню Brave (три точки) → **«Добавить на главный экран»**.
4. Запускайте с рабочего стола — откроется как обычное приложение.

Если внизу видна плашка «Whisper-сервер не отвечает» — сервер в Termux не запущен.

---

## Функции

- Диктовка кнопкой **«Диктовать»** или клавишей **F2** (Esc — стоп)
- Набор с клавиатуры, редактирование, автосохранение
- Заметки: поиск, сортировка (по дате, по названию)
- Экспорт заметки или всех заметок в `.txt`
- Тёмная тема, горячие клавиши, работа без интернета

## Как это работает

- Браузер пишет звук с микрофона, нарезает на 4-секундные WAV-чанки и шлёт их на `http://127.0.0.1:8080/inference` (запросы на localhost браузер считает безопасными, mixed content не возникает).
- whisper.cpp распознаёт чанк и возвращает текст, который дописывается в заметку через пробел.
- Заметки хранятся локально в браузере (localStorage), на сервер ничего не отправляется кроме аудио.
